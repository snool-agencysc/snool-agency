# SNOOL

A SNOOL é uma agência digital focada na criação de soluções digitais — landing pages, sites institucionais e presença digital — para MEIs e pequenos negócios, com atuação inicial em Joinville/SC.

## Sobre o projeto

Este repositório contém o site institucional e portfólio da SNOOL. O site tem como objetivo apresentar a agência, seus serviços e projetos, além de facilitar o contato direto com potenciais clientes via WhatsApp.

## Serviços

- **Landing Pages** — páginas de conversão focadas em um objetivo específico.
- **Sites Institucionais** — presença digital completa para apresentar a empresa, seus serviços e formas de contato.
- **Presença Digital** — identidade digital personalizada de acordo com a necessidade de cada negócio.

Cada projeto é desenvolvido sob medida para o cliente, considerando seu público e objetivos.

## Projetos

O portfólio apresentado no site inclui projetos demonstrativos, desenvolvidos para representar diferentes possibilidades de atuação da SNOOL em segmentos como estética, gastronomia e serviços automotivos. Essa natureza conceitual é indicada de forma transparente na própria interface do site.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES Modules)
- SVG

Projeto estático, sem frameworks ou etapas de build.

## Recursos

- Design responsivo, com layout adaptado para desktop, tablet e celular.
- Navegação acessível por teclado, com foco visível e atributos `aria-expanded` no menu e no FAQ.
- Suporte a `prefers-reduced-motion` em todas as animações.
- Metadados de SEO (título, descrição, Open Graph, canonical) e `sitemap.xml`/`robots.txt`.

## Estrutura do projeto

```
snool/
├── assets/       → imagens, ícones e logos
├── css/          → estilos organizados por responsabilidade
├── js/           → scripts organizados por funcionalidade (ES Modules)
├── projetos/     → páginas demonstrativas do portfólio
├── index.html
├── robots.txt
├── sitemap.xml
└── README.md
```

## Desenvolvimento local

O projeto é 100% estático, sem dependências ou build. Basta abrir o arquivo `index.html` diretamente no navegador, ou servi-lo com qualquer servidor de arquivos estáticos de sua preferência.

## Publicação

O projeto é compatível com qualquer hospedagem de arquivos estáticos (Netlify, Vercel, GitHub Pages, Cloudflare Pages, entre outras). Inclui um `netlify.toml` com configuração de headers de segurança para deploy na Netlify.
